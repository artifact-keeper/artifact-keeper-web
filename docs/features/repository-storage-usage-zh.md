# 仓库存储用量面板

仓库详情视图显示一个 **存储** 面板，报告仓库真实、去重后的存储占用 —— 而不仅仅是粗略的逻辑大小。它由后端史诗 [`artifact-keeper#2056`](https://github.com/artifact-keeper/artifact-keeper/issues/2056) 中的按仓库存储端点支撑。

## 它显示什么

| 字段                     | 含义                                                                                 | 谁能看到                             |
| ------------------------ | ------------------------------------------------------------------------------------ | ------------------------------------ |
| **逻辑大小**             | 去重前所引用制品大小的总和（与仓库的 `storage_used_bytes` 相同）。                   | 所有人                               |
| **Blobs**                | 支撑该仓库的、去重后不同存储 blob 的数量。                                           | 所有人                               |
| **物理（已存储）**       | 内容寻址去重后实际存储的字节。                                                       | 管理员，或按仓库作用域下的任何查看者 |
| **去重比率**             | `逻辑 ÷ 物理`（例如 `2.50×`）。                                                      | 管理员，或按仓库作用域下的任何查看者 |
| **节省量**               | 去重从逻辑占用中去除的量，以字节与百分比表示。                                       | 管理员，或按仓库作用域下的任何查看者 |
| **唯一 vs 共享**         | 一个条形图，将物理存储拆分为本仓库独有的字节与与其他仓库共享的字节。                 | 管理员，或按仓库作用域下的任何查看者 |
| **实例唯一（所有仓库）** | 跨所有仓库的实例级唯一物理字节。                                                     | 仅管理员                             |
| **当前可回收**           | 关于收集无引用 blob 可释放多少物理存储的按需估算（垃圾回收干跑）。不会删除任何内容。 | 仅管理员                             |
| **计算时间**             | 数字的新鲜度（悬停查看精确时间戳）。                                                 | 所有人                               |

## 去重作用域与实例注意点

面板会标注仓库的 **去重作用域**：

- **按仓库去重**（通常为文件系统后端）—— 物理、唯一与共享数字仅限本仓库。
- **实例级去重**（通常为对象存储后端）—— 去重在整个实例范围内合并，因此物理/唯一/共享数字反映的 blob 可能与 _其他_ 仓库共享，不能单独归因于本仓库。面板会在内联说明中呈现这一注意点。

## 字段可见性（安全）

在实例作用域后端上，去重明细可能泄露其他租户仓库的信息，因此后端（[`artifact-keeper#2560`](https://github.com/artifact-keeper/artifact-keeper/issues/2560)）对实例作用域下的非管理员查看者**省略** `physical_bytes`、`unique_bytes`、`shared_bytes` 与 `dedup_ratio`。在这种情况下，面板只显示逻辑大小与 blob 数量，外加一条简短说明：详细分解仅限管理员使用。`instance_unique_bytes` 数字与可回收估算在 API 与 UI 中都仅限管理员。

## 尚未包含

文件夹 / 路径树存储汇总将单独跟踪以在后续发布中实现，**不**属于此面板的一部分 —— 本面板仅限仓库级别。
